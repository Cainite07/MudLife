# MudLife 宣传图制作说明

## 最终统一规范

三张成图使用同一固定模板输出，避免分别生成时手机比例发生变化。参考设计来自内置 image_gen 的暖纸、浅鼠尾草与奶油白分层边框方案；最终界面与排版由可编辑页面组件统一绘制，所有数据虚构。

| 项目 | 固定值 |
| --- | --- |
| 三张画布 | 1600 × 1000 px，横版 8:5 |
| 每台手机外框 | 354 × 739 px，宽高约 1:2.09 |
| 每台手机内容区 | 330 × 715 px |
| 手机顶部 | 外框 y=168 px，屏幕 y=180 px |
| 边框、圆角与阴影 | 复用同一手机组件 |
| 界面缩放 | 360 × 780 的逻辑页面等比输出 |
| 账单余额卡 | 高100逻辑像素，比旧宣传稿118缩小约15% |
| 底部手势线 | 无 |
| 页脚 | 演示数据 / MudLife |

首页有四个底部导航入口，使用码详情与首次引导页不添加底部导航。付款码使用空白占位，使用码使用圆点，不包含可用支付信息、真实账号或设备标识。

## 重新导出

需要 Pillow 和 Windows Microsoft YaHei 字体。

```powershell
# 预览导出到忽略的构建目录
python scripts/render_promos.py
# 更新本目录三张最终图片
python scripts/render_promos.py --final
```

overview.png 为品牌与付款/账单概览，daily.png 为首页/使用码/首次引导，bills.png 为账单功能说明。三张保持相同画布和设备尺寸，不再输出单独的竖版海报。

## 图像参考设计提示

内置 image_gen 用于边框、配色和版式探索。设计要求：暖纸黄与浅鼠尾草折页背景，墨绿文字，奶油白外框、浅香槟色夹层与柔和高光投影；圆润但自然的手机比例，卡片接近实际应用并仅适度放大；不使用黑色边框或手势线，页脚只保留“演示数据”。最终尺寸以模板固定值为准，不依靠生成模型猜测长宽。
